# 03 Execution — R1〜R3（横方向の「1つの基準 → 4つの制作判断」）

対象: `03-r1.html` / `03-r2.html` / `03-r3.html`
前提: 原稿は確定版をそのまま使用（見出し・本文・基準・4つの制作判断・実装タグ、増減なし）。
過去14案で不採用になった方向（体制比較・引き継ぎ論・制作力の列挙・6STEP工程）は使っていない。

## 3案に共通すること

- 幅1440pxの座標系を `.frame` として中央に置く（01 と同じ方式）。見出しブロックは 01 と同座標（left 100.8 / top 117）
- 巨大英字 `Execution` は Zen Kaku Gothic New 900 / 216px / -8.64px / 黒7%、left 0 / top 138（01 と同じ）
- リード2段落は右カラム（left 790 / top 185 / 幅550）に置き、図を全幅で使うための高さを確保
- **図の方向は左→右または上→下の一方向のみ。** 中央に基準を置いて周囲へ配る放射・円形は使わない
- 技術タグ（スマホ対応 / WordPress / 表示速度 / フォーム / 計測設定）は **「実装」の判断文の下にだけ**、13px・sand 地の小さなピルで添える。他3領域には付けない
- 級数: 領域名 22px（R3 は 20px）、判断文 16px / 27px、タグ 13px。絶対配置のラベルは `white-space:nowrap`
- 動きは IntersectionObserver（`.rv` → `.in`、図は `.on`）。`prefers-reduced-motion` では即時表示。静止でも図として成立する
- 画像素材なし。線は CSS または インライン SVG

## R1 「左に基準、右に4つ横並び」 — 3案の中で最も確実な案

### 何を狙ったか
左端に黒い基準ブロック（「基準」キャップ＋一文を3行組み）を置き、その右端から **1本の赤い線（3px）** が右へ伸びて、4枚の白いカードを同じ高さ（y=44）で貫く。線がカードの間の隙間も通ることで「同じ1本が4つを通っている」ことが読める。カード上の線の通過点には赤い正方形の結節点（白いリング付き）を置き、カードの文字は線の下から始まる。基準→判断の因果を、最も素直な「左から右」の読み順で見せる。

### 01・02との差
- 01（放射）: 中央に集まる求心構造。R1 は左端に起点を置き **右へ一方向に流す** 構造。円・中央配置を持たない
- 02（縦線）: 1本の線が上から下へ5地点を縫う。R1 は線が **横一直線**で、地点ではなく4枚のカードを横断する。線の曲がり（S字）もない

### セクション総高さ
**880px**（見出し 117〜319、リード 185〜約372、図 470〜770、下余白 110）

### 実装コスト
低。CSS グリッド（252px + 4カード）と `<line>` 1本の SVG のみ。線の描画は `pathLength` + `stroke-dashoffset`。JS は IO のリビールだけ。

### モバイル
- 901〜1439px: 絶対配置を解いて縦に流す（見出し → リード → 図）。図はグリッドのまま幅に追従
- 900px以下: 基準ブロックを上、カードを1列に縦積み。横の赤線は非表示にし、各カードの左上に赤い結節点だけ残す。読み順は「基準 → 4つ」で同じ。h2 は 32px/48px、英字は 120px

## R2 「上に基準の帯、下に4列」

### 何を狙ったか
基準の一文を **画面幅いっぱいの黒い帯（1440×140）** として上に置く。帯であること自体が「この基準は全部にかかる」の表現。帯の下端に赤の細線（3px）を敷き、そこから **4本の短い赤線（56px）** が等間隔に降りて、4つの制作判断に着地する。着地点は赤い正方形。上段=1つ／下段=4つの階層を、水平に広い帯と縦の短い分配線で見せる。

### 01・02との差
- 01（放射）: 中央1点に3つが集まる。R2 は **上の全幅帯から下の4つへ分配**。起点が「点」ではなく「帯」なので、形の上で放射とは一目で別物
- 02（縦線）: 1本の長い線が縫う。R2 の縦線は **4本・短い・並列**。上下の階層関係を示すだけで、経路や順序を表さない

### セクション総高さ
**960px**（見出し 117〜319、リード 185〜約372、帯 470〜610、4列 610〜約856、下余白 約100）

### 実装コスト
低〜中。帯は全幅 `div`、4列は CSS グリッド、降りる線と着地点は `::before/::after`。帯の登場は `clip-path:inset()` を左から開く。JS は IO のみ。

### モバイル
- 901〜1439px: 縦流し。帯は全幅のまま、4列はグリッド維持
- 900px以下: 帯は高さ自動・パディング付きで、キャプションと一文を縦に並べる（一文 26px）。4列は1列に縦積みし、各項目の左に赤い縦線を通して「帯から降りた」関係を残す

## R3 「基準を文として大きく組む」

### 何を狙ったか
図を描かない。基準の一文を **Zen Kaku Gothic Antique 900 / 80px / 100px、2行** で主役として組む（「誰に、何を伝え、」／「どの行動につなげるか」）。上に赤い短い罫と「基準」キャップ。その下に 1px の罫を全幅に引き、4つの制作判断を **注釈のように小さく（領域名 20px / 判断文 16px）横一列** に並べる。大きい一文が上、小さい4項が下、という級数の階層だけで「1つの基準が4つに及ぶ」を読ませる。文組みで解くので、01・02 の「線図」の系列から完全に外れる。

### 01・02との差
- 01（放射）・02（縦線）はどちらも線図。R3 は **線図を持たない**（あるのは注釈を区切る水平罫1本のみ）ので、形の混同が起きない
- セクション全体がタイポグラフィで構成されるため、01・02 の後に「図・図・文字」というリズムの変化にもなる

### セクション総高さ
**1020px**（見出し 117〜319、リード 185〜約372、一文 466〜約688、罫 748、注釈 774〜約932、下余白 約88）

### 実装コスト
最低。すべてテキストと CSS グリッド。罫の伸びは `::before` の `scaleX`。JS は IO のみ。フォント読み込み前に 80px の行が折り返さないよう `white-space:nowrap` を行 span に付けている（2行×10文字で 1440 幅に十分収まる）。

### モバイル
- 901〜1439px: 縦流し。一文は 64px/80px に落とす
- 900px以下: 一文は 40px/54px で自然折り返し可（nowrap 解除）。注釈は1列に縦積み（row-gap 28px）。罫はそのまま上に1本
