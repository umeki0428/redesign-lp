# Figma → コーディング 受け渡し手順（無料プラン・フレーム単位）

Figma無料プランでは Dev Mode MCP が使えないため、**SVG＋PNGの2点セット**で渡す。
この2つがあれば、Dev Mode に近い精度で実装できる。

## なぜSVGか

SVGには**各要素の座標・サイズ・色・フォント名・級数・字間が数値で入っている**ため、
スクショから目視で起こすより格段に正確。PNGは「最終的な見た目の正解」として突き合わせに使う。

## 手順（フレーム1つごと）

### 1. SVGを書き出す

Figmaでフレームを選択 → 右パネル下部の **Export** → `SVG` を選んで Export

**重要な設定**
- **「Outline Text」はオフ**（オンにすると文字がパスになり、文言も級数も読めなくなる）
- 「Include "id" Attribute」はオンにしておくとレイヤー名が残って読みやすい

※ 右クリック → Copy/Paste as → **Copy as SVG** でも可（クリップボード経由）

### 2. PNGも書き出す

同じフレームを **PNG / 2x** で Export（見た目の正解として使う）

### 3. 置く

```
design/v13/incoming/
  01-mv.svg
  01-mv@2x.png
  02-problem.svg
  02-problem@2x.png
  ...
```

ファイル名は `連番-セクション名` で。デスクトップとモバイルの両方がある場合は
`01-mv-sp.svg` のように `-sp` を付ける。

### 4. 写真・イラストがある場合

フレーム内に配置した画像は SVG に埋め込まれないことがあるので、**個別に書き出して**
`design/v13/assets/` に置く（PNG/JPG/SVG どれでも可）。

### 5. 伝えてほしいこと

- どのセクションか、デスクトップ幅とモバイル幅
- **動きの指定**（下記の「採用する動き」参照）
- 迷っている箇所があれば「ここは仮」と添える

## 採用する動き（DESIGN.md §21）

実装時に再現する候補。どのセクションに適用するか指示があれば合わせる。

| 動き | 参照元 |
|---|---|
| 図のアニメーション（線が描画される／同じ図が状態を変えて再登場） | `design/v12/design-B.html` |
| 文字の出方（縦組みの1文字ずつリビール） | `design/v12/design-A.html` |

## 実装方針

- **ゼロから新規実装**（既存 v8/v11/v12 の構造は流用しない）。Figmaのデザインに忠実に書く
- 動きだけ v12 から移植する
- ロゴは `design/v13/assets/logo.svg`（配置済み）
- 1440px / 390px で破綻しないことを実測で確認する

## 補足

- 全セクション揃ってから渡す必要はない。**1セクションずつでも進められる**
- まずMV（ファーストビュー）だけ渡してもらい、精度と進め方をすり合わせてから残りを展開するのが安全
