# v11 — 参考サイト準拠の「柔らかい多色」版 [2026-09-03]

Fable 5.1 が `refs/` の参考サイト画像を観察し、ゼロから設計・実装。

## 経緯

v10 および fable-test のC案は、参考サイトを見せたにもかかわらず「ロゴが赤だから」という理由で
**赤・黒が主役の強い配色**になり、参考の柔らかさが失われていた。
v11 では以下を明示して作り直した（`ART-DIRECTION.md`）。

- 柔らかい低彩度の多色を**配色の主役**にする
- 赤 `#d93832` は**ロゴ内とごく限定的なアクセントのみ**。色面には使わない
- 同業サイトなので参考の色をそのまま写さず、読み取ったトーンを自分で調律する

## 検証結果（実測）

- 12セクション実装、ページ高さ 10,578px
- 1440px / 390px とも横スクロールなし、はみ出し要素0件
- セクション背景色を実測し、ペールトーンが実際に切り替わることを確認（赤・黒への偏りなし）
- 見出しは文節を `inline-block` の span で包み、どの幅でも語の途中で折り返さない
