絵コンテ → 完成までの作業フロー

画像生成は GPT Image 2、動画生成は Higgsfield、合成は手元の ffmpeg。クレジットを使うのは工程4だけで、そこに入る前に静止画で品質を確定させる。

  1. 01

    絵コンテで構図とカット割りを確定

    0 credit

    このページ。場面・仕草・テロップ文言をここで固める。ここが曖昧なまま先に進むと、生成のやり直しがそのままクレジットの損失になる。

  2. 02

    GPT Image 2 でキーフレームを生成（8枚）

    0 credit

    各カットの 開始フレームと終了フレームを静止画で作る。プロンプトは docs/STORYBOARD.md に英語で用意。文字・ロゴ・判別できる顔は一切生成させない。B案のCUT2は新規生成ではなく、CUT1の画像を編集して陳列だけ差し替える（同一ロケの説得力はここで決まる）。

  3. 03

    受け入れチェック

    0 credit

    assets/storyboard/ に保存して Claude Code に渡す。文字の混入・顔の写り込み・トーンのばらつき・A案の同一人物性を目視で確認し、直しは工程2に戻す。

  4. 04

    Higgsfield で動画化（4本 × 5秒）

    80 credits

    採用したキーフレームを start / end の両端固定で渡して生成する。両端を握るぶん動きの暴れが減り、一発採用率が上がる。残り30クレジットがリトライの余力。

  5. 05

    CUT3（ロゴ落ち）を制作

    0 credit

    LPのトークンをそのまま使い、HTML/SVGのアニメーションから連番画像で書き出す。AIには一切触らせないので、ロゴと文字は常に完璧。

  6. 06

    結合・テロップ・矢羽の合成

    0 credit

    3カットを繋ぎ、赤の矢羽とテロップを ffmpeg で乗せる。テロップ位置は絵コンテの赤い破線枠で固定済み。

  7. 07

    縦横比の展開（9:16 / 1:1）

    後日

    まず 16:9 の2本を入稿して数字を見る。伸びた側だけを縦・正方に展開する。各カットは 9:16 セーフエリア内に主題を収めてあるので、切っても成立する。

先に決めてほしいこと

  • A案の場面 — カフェでよいか。オフィス・自宅・移動中も選べる。また「立ち上がって歩き出す」より「その場で電話をかける」のほうが結果として分かりやすいかもしれない
  • B案の業種 — パン屋でよいか。青果店・雑貨店・花屋も候補。花屋は画が華やかで、かつLPの低彩度トーンとも噛み合う
  • テロップ文言 — 落ちの2文（「届け方と伝え方で、結果は変わる。」「ホームページ制作なら、リデザイン。」）以外はすべて仮。特にA案CUT1の「静かに離脱されていく。」は強すぎないか
  • ナレーションの有無 — 音声を入れるか、テロップだけで見せるか。P-Maxは音声オフ再生が多いので、テロップだけでも成立する設計にしてある
