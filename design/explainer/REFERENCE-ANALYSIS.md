## 2. 真似すべき作法（試作に欠けていたもの）

### 2.1 画面の使い方
- **背景の色面が章を分ける。** 悩み＝灰、解決＝青緑、仕組み＝淡い水色。色が変わることで話題の切り替わりが伝わる
- **見出しは上、字幕は下、絵は中央。** 左に文字・右に絵という固定配置ではない
- 絵は**丸で切り抜いて**配置する。白い半円の台に乗せる、丸の中に人物を入れる、など
- 要素には**小さなラベル**（黒いピル、細い文字）が付く。「固定カメラ」「ソラカメ」など

### 2.2 動きの作法
- **積み上げる。** 出た要素は消さず、画面に残して足していく。1つの図が10秒かけて完成する
- **ナレーションの一文ごとに1つ動く。** 「撮影し、」で矢印、「保存します」でクラウド、と対応している
- **矢印は描かれる。** 点線が流れる、線が伸びて先端に矢が出る
- **吹き出しがポンと出る。** 効能や感想は吹き出しで短く（3〜6文字）
- 画面は**常にどこかが動いている**。止まる時間がない

### 2.3 文字
- 字幕は画面の下・中央、**背景の箱なし**、小さめ（画面の高さの約 3%）。ナレーションと同じ文を、読点で区切って出す
- 見出しは上・中央で、字幕より少し大きい程度。**画面の半分を占める巨大なテロップは使っていない**
- 強調はピル（角丸の色面に白文字）と色

## 3. 試作がだめだった理由（対応表）

| 試作 | 参考動画 |
|---|---|
| 左に大きなテロップ、右に絵の固定配置 | 章ごとに構図が変わる。テロップは主役ではない |
| 絵は出て止まるだけ | 出たあとも図として組み上がっていく |
| 胸から上の人物を大きく1〜2人 | 丸に切り抜いた小さめの絵を複数、台の上に並べる |
| 字幕が白い箱で大きい | 箱なし・小さめ・下中央 |
| 背景は終始同じ | 章ごとに背景の色面が変わる |
| 10秒で3〜4個の要素 | 10秒で7〜10個の要素が順に増える |

## 4. 作り直しの方針

1. 60秒を**6つの章**に分け、章ごとに背景の色面を変える（クリーム／黒／淡い赤／白／ティール／赤）
2. 各章で**1つの図を組み上げる**。要素は消さずに足す
3. ナレーションを読点で区切り、**区切りごとに1つ動かす**
4. 素材は「丸に収まる小さめの絵」「アイコン」「吹き出し」の3種類を作り分ける
5. 字幕は箱なし・下中央・小さめ。テロップは短い言葉だけ

色は LP の配色（クリーム #f5f2eb／墨 #2b2b2b／赤 #d93832／ティール #b0dedb）を使う。
