# Handoff: RE DESIGN 制作会社LP(v7)+ 下層ページ「制作体制について」

## Overview
Web制作事業「RE DESIGN」のサービスLP(1ページ)と、その下層ページ「制作体制について(制作業界の、少し不都合な話。)」のデザインハンドオフ。LPは「問題提起 → 解決策01-03 → 公開後支援 → 実績 → 料金 → 制作の流れ → 会社概要 → FAQ → お問い合わせ」の構成。下層ページはLPの03(一貫担当)セクション内のテキストリンクから遷移する。

## About the Design Files
このバンドルのHTMLファイルは **HTMLで作成されたデザインリファレンス(プロトタイプ)** であり、そのまま本番コードとして流用するものではない。実装先のコードベース(WordPressテーマ、React等)の既存の環境・慣習・ライブラリに合わせて **再実装** すること。環境が未定の場合は、案件特性(WordPress中心のCMS構築が前提)に合う技術を選定して実装する。

- `.dc.html` ファイルは独自ランタイム(`support.js`)上で動くテンプレート形式。`<x-dc>` 内のマークアップとインラインスタイルが仕様。`{{ ... }}` はランタイム変数(下記 State 参照)。
- `image-slot.js` / `<image-slot>` は画像プレースホルダー用のプロトタイプ部品。実装時は通常の `<img>` に置き換える。

## Fidelity
**High-fidelity。** 色・タイポグラフィ・余白・レイアウトは最終意匠としてピクセル準拠で再現すること。ただし実績画像・MV内スクリーンショットはダミー(差し替え前提)。

## Interactions & Behavior
- 全CTA(赤ピル)→ LPの `#s12` お問い合わせへアンカースクロール。hover は opacity .8(全リンク共通)。
- 03セクションのテキストリンク → 下層ページへ遷移。下層ページのパンくず「トップ」→ LPへ戻る。
- 実績カルーセル: 前後ボタンで `transform: translateX` をスライド(transition .5s cubic-bezier(.2,.7,.2,1))、非アクティブカードは opacity ダウン。
- レスポンシブ: `.rd-split` は920px以下で1カラム。カードグリッドは `repeat(auto-fit, minmax(280px, 1fr))` 系。分業チェーン図はflex-wrapで折返し可。

## State Management
プロトタイプのランタイム変数(実装時の対応):
- `designBg` / `supportBg` — セクション背景(調整用トグル。実装時は確定値をベタ書き)
- `trackShift`, `op0`–`op2` — 実績カルーセルの位置と各カードの不透明度(カルーセルライブラリまたは軽量JSで実装)
- データフェッチなし。フォームはお問い合わせセクションのみ(実装先の仕様に従う)。
