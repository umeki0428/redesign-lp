# Handoff: RE DESIGN LP v6（全12セクション）

## Overview
RE DESIGN（ホームページ制作・Web集客支援）のLP。MVからお問い合わせまで全12セクション。
docs/STRUCTURE.md・CONTENT.md・DESIGN.md（umeki0428/redesign-lp）を起点に制作し、§6〜12はこのデザイン作業で新規追加した。

## About the Design Files
同梱の `RE DESIGN LP v6.dc.html` は **HTMLで作ったデザインリファレンス**（プロトタイプ）であり、そのまま本番コードとして流用するものではない。
リポジトリの既存環境・規約（静的HTML/CSS、または採用するフレームワーク）で**このデザインを再実装**すること。`support.js` / `image-slot.js` はプレビュー用ランタイムなので実装には不要。
ブラウザで `RE DESIGN LP v6.dc.html` を直接開けば全体を確認できる。

## Interactions & Behavior
- 全CTA（ヘッダー/MV）は `#s12` へのアンカースクロール
- §07カルーセル: state `work`(0..2) を prev/next で循環、タグ・タイトルも連動
- §12フォーム: submitで preventDefault → sent=true でサンクス表示（実装時は実際の送信処理に置換。バリデーションはHTML required）
- ホバー: リンクは opacity .8
- レスポンシブ: 2カラムは920px以下で1カラム、カード群は auto-fit minmax で折返し

## State Management
- `work: number` — 実績カルーセルのアクティブ番号
- `sent: boolean` — フォーム送信済み
- 調整用props（実装時は定数化してよい）: `accent`=#d93832, `lime`(ダーク面アクセント)=#ff806f, `sec01`=timeline
