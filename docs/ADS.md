## 7. 作成

`tracking/ads/`。アカウントが有効になったら実行する。

1. `python3 tracking/ads/create_conversion.py` … コンバージョン「問い合わせ」を作り、GTM に入れる ID とラベルを出す
2. `python3 tracking/ads/create_campaign.py` … 検証だけ（何も作らない）。文字数や規定の違反をここで見つける
3. `python3 tracking/ads/create_campaign.py --apply` … 停止状態で作成
