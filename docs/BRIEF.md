## 4. ポジショニング

- **旗: 考える人と、つくる人を分けない。** [2026-08-31確定]
  - 人数や「すべて一人で制作すること」を訴求するコピーではない
  - 事業・顧客を理解して伝える内容を設計した責任者が、原稿・デザイン・実装・公開まで関わり続ける体制を示す
  - 案件に応じて専門パートナーと協働しても、この考え方とは矛盾しない
  - 業界構造: 多くの制作会社は営業（受注まで）→ディレクター（受注後）と分業しており、クライアントの意図と熱量が引き継ぎで落ちる
- **訴求する効能3つ**（原稿の理由づけに使う） [2026-08-31確定]

  2. 「誰に、何を、どう伝えるか」が原稿・デザイン・実装まで一貫する
  3. 設計責任者が窓口となり、必要な専門性を組み合わせながら公開まで進められる
- **表現の禁止事項** [2026-08-31確定]
  - 比較対象は「分業そのもの」ではなく、工程ごとに意図が分断される状態とする
  - 「自社一貫」「すべて一人で担当」「外注しない」など、実態以上に内製を強調する表現は使わない
  - 分業そのものや他社を否定する表現、中間マージンなど価格の話は使わない
- **AIの位置づけ** [2026-08-14確定 / 2026-08-31調整]
  - AIで工数が下がったから設計者が最後まで持てる、という因果で語る。AI自体を主役の訴求にしない
  - 品質の説明: プロがAIの得意領域だけをAI化し、不得意な領域は手作業で調整する。素人のAI制作とは品質が違う
  - **セクション01〜03の主訴求にはAIを含めない** [2026-08-31確定]。AIの話は §11 FAQ で扱う
