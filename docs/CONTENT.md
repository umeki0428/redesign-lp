## 3. 事業理解と伝える軸（Solution 01） [2026-08-31改訂]

（背景ラベル：Solution ／ 番号：01）

### デザインの前に、
### まず事業を整理する。

RE DESIGNのホームページ制作は、いきなりページ構成やデザインを決めるところから始まりません。

現在の課題、お客様の顧客、商品やサービスが提供できる価値について伺い、事業への理解を深めます。

対話を通じてそれぞれを整理し、ホームページで「誰に、何を伝えるべきか」を一緒に見つけていきます。

**図解（三角配置）**

| 位置 | ラベル | 補足 |
|---|---|---|
| 頂点 | 課題 | 何を変えたいか |
| 左下 | 顧客 | 誰に届けるか |
| 右下 | 事業 | 何を提供できるか |
| 中央 | 伝える軸 | 3要素を整理した結果として導く |

**図解の着地：対話から見つける。誰に、何を伝えるべきか。**

## 4. 伝え方・届け方の設計（Solution 02） [2026-08-31改訂・方向性確認中]

（背景ラベル：Design ／ 番号：02）

### 事業の価値を、
### 届くかたちへ。

価値のある商品やサービスも、ただホームページに掲載するだけでは顧客に届きません。

どこで見つけてもらい、何に興味を持ち、どの情報から理解や信頼につなげるのか。01で整理した「誰に、何を伝えるか」をもとに、顧客との接点から問い合わせまでを一つの流れとして設計します。

| # | 顧客の段階 | RE DESIGNが設計すること |
|---|---|---|
| 01 | 見つけてもらう | 検索・広告・SNSなど、顧客との接点を設計する。 |
| 02 | 興味を持ってもらう | 顧客の課題と事業の価値を結び、「自分に関係がある」と感じる訴求をつくる。 |
| 03 | 理解してもらう | 商品やサービスの違いを、判断しやすい言葉と情報の順番で伝える。 |
| 04 | 信頼してもらう | 実績・事例・お客様の声など、選ぶための根拠を整える。 |
| 05 | 行動してもらう | 迷わず相談できる導線と、問い合わせのきっかけをつくる。 |

## 5. 設計と制作を分断しない体制（Solution 03） [2026-08-31改訂]

（背景ラベル：Process ／ 番号：03）

### 考える人と、
### つくる人を分けない。

[2026-08-31 変更: 旧「ヒアリングから公開後まで、担当者は変わりません。」から差し替え]

事業や顧客について理解し、「誰に、何を、どう伝えるか」を考える。その意図を共有したまま、原稿・デザイン・実装へ落とし込みます。

工程ごとに役割を切り離すのではなく、設計責任者が制作・公開まで関わり続けることで、事業への理解と設計意図を失わずにホームページとして形にします。

案件に応じて専門パートナーと協働する場合も、事業について伺い、伝える内容を設計した担当者が最後までプロジェクトに関わります。

**Before｜工程ごとに担当が分かれる場合**

ヒアリング → 情報設計 → 原稿・デザイン → 実装・公開

担当が変わるたびに伝達が発生し、事業への理解や設計意図が薄れてしまうこともあります。

**After｜RE DESIGNの制作体制**

ヒアリング → 情報設計 → 原稿・デザイン → 実装・公開

**設計責任者がすべての工程に関わり続ける。**

事業への理解と設計意図を、制作の最後までつなげます。

（補足・小さく表示）案件に応じて専門パートナーと連携します。

## 6. 公開後の支援

（背景ラベル：Support）

### 公開は、ホームページ活用の
### スタートです。

つくって終わりにはしません。公開後のデータを見ながら、改善と集客を続けていきます。ホームページは、公開してからが本当のスタートです。

**01 アクセス解析・改善提案**
計測データをもとに、閲覧状況や問い合わせの動きを確認します。どのページで離脱しているか、どの経路からの問い合わせが多いかを見て、次に直す場所をご提案します。

**02 更新・保守サポート**
お知らせや実績の更新、WordPressやプラグインの保守など、日々の運用を支えます。ご自身で更新できる範囲と、お任せいただく範囲を最初に決めます。

**03 集客施策の伴走**
SEO、広告、SNSなど、事業に合った集客施策を一緒に考え、実行を支援します。何から始めるべきかの判断からご相談いただけます。
