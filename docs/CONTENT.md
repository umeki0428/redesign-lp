## 5. 一貫担当（Solution 03）

（背景ラベル：Process ／ 番号：03）

### ヒアリングから公開後まで、
### 担当者は変わりません。

[2026-08-26 変更: 旧「最初に話した人が、最後までつくる。」から差し替え]

工程ごとに担当者が変わらないため、対話の中で得た事業への理解やお客様の意図を薄めることなく、最後まで形にできます。

| 工程 | 説明 |
|---|---|
| ヒアリング・事業整理 | 事業、顧客、課題、目標を対話しながら整理します。 |
| 競合・市場調査 | 競合の訴求や顧客の選び方を調査し、選ばれる理由を明確にします。 |
| 集客・情報設計 | 想定する流入経路を踏まえ、伝える内容と問い合わせにつながる情報設計を行います。 |
| 原稿・デザイン | 事業の価値を、伝わる言葉とビジュアルに落とし込みます。 |
| 実装・CMS構築 | WordPressを中心に、目的や運用体制に合った方法でサイトを構築します。 |
| 公開・運用支援 | 計測環境を整え、公開後の分析や改善、必要な集客施策まで継続して支援します。 |

## 6. 公開後の支援

（背景ラベル：Support）

### 公開は、ホームページ活用の
### スタートです。

つくって終わりにはしません。公開後のデータを見ながら、改善と集客を続けていきます。ホームページは、公開してからが本当のスタートです。

**01 アクセス解析・改善提案**
計測データをもとに、閲覧状況や問い合わせの動きを確認します。どのページで離脱しているか、どの経路からの問い合わせが多いかを見て、次に直す場所をご提案します。

**02 更新・保守サポート**
お知らせや実績の更新、WordPressやプラグインの保守など、日々の運用を支えます。ご自身で更新できる範囲と、お任せいただく範囲を最初に決めます。

**03 集客施策の伴走**
SEO、広告、SNSなど、事業に合った集客施策を一緒に考え、実行を支援します。何から始めるべきかの判断からご相談いただけます。
