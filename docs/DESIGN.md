## 1. トンマナキーワード

3〜5語まで。誰にでも当てはまる語（信頼感・シンプル・モダン等）は禁止。
「AよりB」の対比形式で書く。

- 原色より低彩度 — 彩度を落とした色面と白・墨で構成する。目を引く色で押さない [仮]
- 写真より文字と図 — 写真は使わない。タイポグラフィ・番号・ラインアイコン・背景ゴースト文字で語る。飾るための装飾はしない [2026-08-26確定]
- 柔らかいより率直 — 見出しは言い切る。婉曲な表現で薄めない [仮]
- 賑やかより静かな熱量 — 動きは1セクション1つまで。読ませる演出に限定する [仮]
- 企業的な華やかさより実務の誠実さ — 盛った実績演出をせず、正直な開示をデザインでも貫く [仮]

## 2. 避けたいもの

| `animation` / `transition` / `will-change` | 中間状態でキャプチャされるのを防ぐ。MVの図形は整列状態で固定 |
| `clip-path` | 変換されない |
| `<details>` / `<summary>` → `<div>` | 閉じた状態で取り込まれ回答が落ちるため、全問開いた状態に |
| `overflow:clip` → `overflow:hidden` | `clip` は未対応 |
| 実績カルーセルの `transform:translateX()` → `padding-left:331px` | transform は落ちる可能性がある |
| `<script>` と `onclick` / `onsubmit` | 静止版のため不要 |
