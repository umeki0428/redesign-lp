## 1. トンマナキーワード

3〜5語まで。誰にでも当てはまる語（信頼感・シンプル・モダン等）は禁止。
「AよりB」の対比形式で書く。

- 原色より低彩度 — 彩度を落とした色面と白・墨で構成する。目を引く色で押さない [仮]
- 写真より文字と図 — 写真は使わない。タイポグラフィ・番号・ラインアイコン・背景ゴースト文字で語る。飾るための装飾はしない [2026-08-26確定]
- 柔らかいより率直 — 見出しは言い切る。婉曲な表現で薄めない [仮]
- 賑やかより静かな熱量 — 動きは1セクション1つまで。読ませる演出に限定する [仮]
- 企業的な華やかさより実務の誠実さ — 盛った実績演出をせず、正直な開示をデザインでも貫く [仮]

## 2. 避けたいもの

| `animation` / `transition` / `will-change` | 中間状態でキャプチャされるのを防ぐ。MVの図形は整列状態で固定 |
| `clip-path` | 変換されない |
| `<details>` / `<summary>` → `<div>` | 閉じた状態で取り込まれ回答が落ちるため、全問開いた状態に |
| `overflow:clip` → `overflow:hidden` | `clip` は未対応 |
| 実績カルーセルの `transform:translateX()` → `padding-left:331px` | transform は落ちる可能性がある |
| `<script>` と `onclick` / `onsubmit` | 静止版のため不要 |

## 23. v13 修正（発注者FB 2026-09-03・1回目）

### 指示と対応

| 指示 | 対応 |
|---|---|
| 各セクションの位置が変 | 1440px超の画面で中身が左に寄っていた。原因と対応は下記 |
| MV右カラムは参考サイトの右カラムを参考に、動きと大きさ | 全高フルブリードの2列無限スクロールに作り替え |

| 文字は v12 A案を参考に、スクロールでふわっと | scroll-timeline を廃し IntersectionObserver 方式へ |

### 「位置が変」の原因

Figma の 1440px 座標をそのまま絶対座標でピン留めしていたため、**1440pxを超える画面で
中身だけが左に寄っていた**（MacBook Pro 14インチ = 1512px などで顕著）。あわせて Problem は
`align-items:flex-start` で、900px に制限した中身が padding の内側で左寄せになっていた。

対応:

- Problem — `align-items:center`。巨大英字は `left:370px` を
  「画面中心から -350px」（1440幅の中心 720 からの差分）に置き換え、どの幅でも Figma と同じ相対位置になる
- Discovery — 1440×874 の座標系を `.dsc__frame` として括り出し、それを画面中央に置く。
  中の絶対座標は Figma のまま
- MV — 左カラムに `max-width:712px`（Figma の 712.81px）を入れ、右カラムは画面右端まで抜く

### MV右カラム（参考: cyber-intelligence.co.jp/lp/gifu/）

参考サイトの実測値:

| | 値 |
|---|---|
| 構成 | 2列。左列は上へ、右列は下へ無限スクロール |
| 速度 | ループ 810px / 40s ≒ **20px/秒**、linear |
| タイル | 349×255 / 角丸4px / 間隔15px |
| 配置 | ヘッダー下から画面右端まで全高フルブリード |

v13 での実装:

- ヘッダー下（y=92）から画面下端まで全高。幅は `clamp(360px, 42.5vw, 660px)` で **1440pxのとき612px**
- 同じ8枚組を2つ並べ、1組ぶん（組の高さ＋間隔）だけ動かして原点に戻す＝継ぎ目が出ない。
  ループ891px / **42s** ≒ 21px/秒で、参考サイトとほぼ同じ速さ
- タイルは v8 の8枚のまま、高さは列幅からの比率。角丸は10px（§22-1 のまま）、間隔は参考サイトに合わせ15px
- トラックは `position:absolute`。そうしないと2組ぶんの高さがそのままセクションの高さになる

### 文字の出方

v12 A案の `.rv`（`opacity:0` + `translateY(18px)` → IntersectionObserver で `.in`）に統一。

- 見出しは行ごとに `<span class="rv">` で分け、`--i` で 0.12s ずつずらす
- これまでの `animation-timeline:view()` は Chrome 以外で効かず、巨大英字のパララックスも
  Figma の位置から動いてしまうため、どちらも廃止
- MVのキャッチコピーだけは v8 のバーワイプを維持（スクロールではなく読み込み時の演出のため）
