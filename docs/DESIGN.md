## 1. トンマナキーワード

3〜5語まで。誰にでも当てはまる語（信頼感・シンプル・モダン等）は禁止。
「AよりB」の対比形式で書く。

- 原色より低彩度 — 彩度を落とした色面と白・墨で構成する。目を引く色で押さない [仮]
- 飾りより実務の空気 — 実際の仕事風景が伝わる写真と、抑えたトーンの幾何学イラストで語る。飾るための装飾はしない [仮]
- 柔らかいより率直 — 見出しは言い切る。婉曲な表現で薄めない [仮]
- 賑やかより静かな熱量 — 動きは1セクション1つまで。読ませる演出に限定する [仮]
- 企業的な華やかさより実務の誠実さ — 盛った実績演出をせず、正直な開示をデザインでも貫く [仮]

  - 素材感: 打ち合わせ・作業風景など「実務の空気」。人物は顔が主役にならない構図を優先（代表を前面に出さない方針と整合）
  - イラスト: 参考サイトの Thinking Lab 型（低彩度パステルのフラットな幾何学図形）に倣う。AIっぽい抽象3D・グラデーションは引き続き不可

- 余白・角丸: tokens.css の変数（セクション上下 132px、コンテナ 1240px、radius 28px）を起点に調整可

### 参考: https://www.symdirect.co.jp/

- 取る:
  - 落ち着いた低彩度の多色配色（白・墨 #2b2b2b＋クリーム・ミント・パープル・グリーン等のペールトーン。原色なし）

  - 墨ステージに置く低彩度パステルのフラットな幾何学イラスト（Thinking Lab の円形コラージュの型）
  - 全面写真のヒーローに色面（シェブロン）を重ね、画面幅いっぱいのロゴタイプを置く構成（実素材が揃うまではダミー写真） [仮]
  - 色面の上に角丸の大判写真カード（縦長・正方形）を1枚置くレイアウト
  - 「01 課題を解く」式の 番号＋短いラベル＋見出し の見出しシステム
  - 墨背景の工程セクション（番号カードを矢印でつなぐ。§5一貫担当の6工程と相性が良い）
  - 画面幅を使った大きな英字タイポグラフィ（控えめに翻訳して使用。マーキー的な繰り返しはそのまま真似ない）

  - スクロールジャック等の重い没入演出、ピン留めのプロジェクトギャラリー（LPは広告の受け皿。CVまでの速度を優先する）

  - 文言・言い回し（同業のため視覚要素のみ参考にする）

### 方向性の整理 [仮]

- 白基調＋低彩度の色ステージ＋角丸写真カード、で全体を組む。写真が主役、タイポグラフィは補助に回す
- 旧方針の「タイポと色面で写真の不在を補う」構成は廃止（写真を使う方針に転換したため）
- 読ませる演出（行単位の塗りつぶし等）は §2 問題提起のみに残す。他セクションは静的に近い見せ方でCVまでの速度を優先

## 5. 出力仕様

- 自己完結の静的HTML1ファイル＋CSS（tokens.cssに変数集約）
- レイアウトは Flexbox / CSS Grid。JSによる描画・アニメーション必須の構造にしない
- 写真はダミー可。ダミー段階では Unsplash の画像URLを直リンク可（納品時に実素材へ差し替え、その時点で自己完結に戻す）。実寸のアスペクト比を維持する
- レスポンシブ: モバイル優先。ブレークポイントは 768px / 1024px
- セクション構成は STRUCTURE.md に完全に従う（増減しない）。文言は CONTENT.md を原本としつつ、デザインに合わせた調整を許可する [2026-08-20 発注者指示]
  - 許可する調整: 長文の圧縮・分割、見出し化・図解化への置き換え、改行位置、強調の付与
  - 禁止: 原稿の趣旨・訴求の変更、新しい主張の追加、確定文言（キャッチコピー・CTA・工程名等）の書き換え
