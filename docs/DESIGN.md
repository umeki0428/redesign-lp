## 1. トンマナキーワード

3〜5語まで。誰にでも当てはまる語（信頼感・シンプル・モダン等）は禁止。
「AよりB」の対比形式で書く。

- 装飾より骨格 — 写真やイラストで飾らず、タイポグラフィと余白で構成する [仮]
- 柔らかいより率直 — 見出しは言い切る。婉曲な表現で薄めない [仮]
- 賑やかより静かな熱量 — 動きは1セクション1つまで。読ませる演出に限定する [仮]
- 企業的な華やかさより実務の誠実さ — 盛った実績演出をせず、正直な開示をデザインでも貫く [仮]

## 2. 避けたいもの

参考URLより効く。具体的に書く。

- AIっぽい抽象3Dイラスト・グラデーションの多用 [仮]
- 全面実写写真のヒーロー（人物・オフィス写真素材が存在しないため。素材サイトの「外国人オフィスワーカー」写真は実態と乖離するので全面禁止） [仮]
- 紫系・金系の配色（参考1の配色は取らない） [仮]
- グラスモーフィズム、過剰なドロップシャドウ [仮]
- スクロールジャック（スクロール位置を奪う固定演出）。参考1の演出は「読む速度を邪魔しない範囲」に翻訳して使う [仮]
- 同業サイト（特に参考2）の文言・言い回しの模倣。訴求が近いため視覚要素のみ参考にする

## 3. 固定する要素

- ロゴ: 専用ロゴなし。テキストロゴ「RE DESIGN」で組む [仮]
- 配色: 旧 `design/tokens.css` を引き継ぐ [仮]
  - ペーパー #f5f2eb（基調背景）／インク #111111（テキスト）／濃色セクション #0d0d0d
  - アクセント赤 #ee4938（CTA・強調）／ハイライトライム #d7ff56（マーカー的強調）／補助ブルー #5e7bff
- フォント: 旧tokens踏襲（Helvetica Neue ＋ ヒラギノ角ゴ系）。Webフォントを使う場合は 日本語: Noto Sans JP ／ 英字: Inter [仮]
- 余白・角丸: tokens.css の変数（セクション上下 132px、コンテナ 1240px、radius 28px）を起点に調整可

## 4. 参考デザイン

### 参考1: https://www.symdirect.co.jp/

- 取る:
  - スクロールに応じて背景色が段階的に変化する演出（セクションの転換を色で語る）
  - リード文がスクロールで1文字ずつ塗りつぶされていく「読ませる」演出（§2問題提起の長文と相性が良い）
  - 画面幅を使った大きな英字タイポグラフィの気持ちよさ（級数差の大胆さ）
  - 1画面1メッセージの情報密度
- 取らない:
  - 紫・金の配色
  - 全面実写写真のヒーロー（素材がない）
  - スクロールジャックの強い没入構造（LPは広告の受け皿。CVまでの速度を優先する）

## 5. 出力仕様

- 自己完結の静的HTML1ファイル＋CSS（tokens.cssに変数集約）
- レイアウトは Flexbox / CSS Grid。JSによる描画・アニメーション必須の構造にしない
- 画像はプレースホルダ可。ただし実寸のアスペクト比を維持する
- レスポンシブ: モバイル優先。ブレークポイントは 768px / 1024px
- セクション構成・文言は STRUCTURE.md / CONTENT.md に完全に従う。デザイン側で文言を書き換えない
