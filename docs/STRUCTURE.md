# STRUCTURE — サイト構成

- 構成: ワンページ（広告の受け皿を兼ねる）
- 記載ルール: 各セクションに「目的／載せる要素／分量の目安」を記載する。デザイン・見た目の話はここに書かない
- 状態: セクション1〜5は構成調整済み。セクション6以降は未調整のたたき台 [仮]

---

## 全体のストーリー（セクション1〜5）

1. RE DESIGNは、ホームページをただつくるだけではない
2. なぜ、ホームページを作ることから始めると失敗するのか
3. 最初に事業を整理し、「誰に、何を伝えるか」を決める
4. 「どう伝え、どう届けるか」を設計する
5. 事業を理解した担当者が、制作から公開後まで一貫して担当する

---

## 1. メインビジュアル

- 目的: RE DESIGNが、ホームページをただ制作するだけの会社ではなく、事業とWeb集客を一緒に考える会社であることを最初に伝える
- 要素:
  - キャッチコピー
  - RE DESIGNの考え方を伝える説明文
  - お問い合わせへのCTA
- 分量: キャッチコピー3行、説明文150字前後、CTA1つ

## 2. 問題提起

- 目的: ホームページは公開するだけで人を集めるものではなく、Web集客全体の戦略から逆算して設計する必要があることを伝える
- 要素:
  - 「ホームページは、作ることから始めると失敗します。」という問題提起
  - ホームページの基本的な役割
  - 「集客装置」と「営業装置」の違い
  - 広告・SNS・検索・紹介から、ホームページ、問い合わせ・商談までの関係
  - 制作前に決めるべき4項目
  - 戦略を決めずに制作する問題点
  - セクション3への橋渡し
- 情報の流れ:
  - 広告・SNS・検索・紹介
  - ホームページで価値を伝え、信頼をつくる
  - 問い合わせ・購入・商談
- 分量: 見出し、本文700〜900字、確認項目4つ。現時点では圧縮せず、Webデザイン時に見せ方と文章量を調整する

## 3. 事業の棚卸し

- 目的: RE DESIGNのホームページ制作が、ページ構成やデザインではなく、事業を理解・整理することから始まると伝える。セクション2で説明したWeb集客戦略を考えるための最初の工程
- 要素:
  - 事業整理から始める理由
  - ヒアリングで確認する内容
  - 「誰に、何を伝えるか」を明確にする工程
  - お客様と一緒に整理する姿勢
- ヒアリング項目:
  - どのようなお客様に選ばれたいのか
  - どのサービスや商品の魅力を伝えたいのか
  - 現在、どのような課題を抱えているのか
  - ホームページを見た人に、どのような行動をしてほしいのか
- 分量: 見出し、本文150字前後、確認項目4つ

## 4. 伝え方・届け方の設計

- 目的: セクション3で整理した「誰に、何を伝えるか」を、実際にユーザーへ伝わる形に設計する工程を説明する。ホームページの構成やデザインだけでなく、集客方法や問い合わせまでの導線も含めて考えることを伝える
- 要素:
  - 文章
  - 写真
  - デザイン
  - ページ構成
  - 問い合わせまでの導線
  - 広告などの流入経路
  - アクセス解析
  - コンテンツ運用
- 分量: 見出し、本文200字前後

## 5. 一貫担当

- 目的: 事業のヒアリングから調査、設計、原稿、デザイン、実装、公開後の支援まで、同じ担当者が一貫して対応することを伝える。単なる制作工程の紹介ではなく、「事業を理解した担当者が、その理解を持ったまま最後まで制作する」というRE DESIGNの強みを示す
- 要素:
  - 一貫担当を伝える見出し
  - 同じ担当者が対応するメリット
  - 担当する6つの工程
  - 工程間で意図や情報が失われないこと
  - AIについては、このセクションでは説明しない
- 担当する工程:
  1. ヒアリング・事業整理
  2. 競合・市場調査
  3. 集客・情報設計
  4. 原稿・デザイン
  5. 実装・CMS構築
  6. 公開・運用支援
- 分量: 見出し、導入文200字前後、6工程×各50字前後
